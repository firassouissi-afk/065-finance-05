# Expense Finance

A standalone C console project implementing a expense-focused finance.

## Build

```powershell
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o project.exe
```

## Run

```powershell
./project.exe
```

You can also pass a number or short text directly:

```powershell
./project.exe 42
```

## Files

- `main.c` - C source code
- `Makefile` - build commands

No third-party libraries are required.
